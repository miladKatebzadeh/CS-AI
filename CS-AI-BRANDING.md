# CS.AI branding

CS.AI is an unofficial personal hobby fork of [Open WebUI](https://github.com/open-webui/open-webui). It is not endorsed by or affiliated with Open WebUI Inc. or Herat University.

The red circular Computer Science emblem was provided by the project owner. A compact, reduced-resolution version derived from that supplied image is used in the web UI, favicons, and splash graphic. For official use of the university emblem beyond personal experimentation, obtain any necessary permissions.

The upstream Open WebUI license is retained in [LICENSE](LICENSE). Customized branding is only permitted under the license's applicable conditions, including the limited-user exception.

## Relevant files

- `static/static/favicon.svg` — favicon containing the supplied emblem
- `static/static/cs-ai-splash.svg` — startup splash with the CS.AI name
- `static/favicon.png` — fallback favicon
- `static/static/favicon.png`, `logo.png`, and other branded PNG assets — compact versions of the supplied emblem
- `src/app.html` — page title and splash references
- `backend/open_webui/env.py` — default server display name
- `static/manifest.json` and `static/static/site.webmanifest` — installed web app identity
